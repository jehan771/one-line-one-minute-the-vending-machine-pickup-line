A single pickup line, spoken by a vending machine to a passing human, for the
[make.fun bounty](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
"One Line, One Minute: The Vending Machine Pickup Line Contest".

The entry program (`main.ts`, Node 22) writes one line to `/output/entry.txt`:

> I usually only fall for exact change, but for you I'd jam my own coil.

It is the machine itself talking — exact change and a jammed coil are its own
world — and the punch lands on the last few words: a machine that only ever
falls for exact change, willing to jam its own coil for one passing human.
Short, speakable in one breath, cheeky and warm rather than creepy.

Run it with:

```
node main.ts
```
